操作说明

订阅导入

  1. 开通套餐后完整复制订阅地址，避免漏掉前缀或令牌。
  2. 打开已安装的客户端，找到订阅 / 配置 URL 输入位置。
  3. 粘贴链接并更新，确认出现节点或策略组。
  4. 若列表为空，检查链接是否被截断，或更换支持该订阅格式的客户端后重试。

连接与规则

全局代理适合需要稳定出口的短时任务；规则分流更适合日常浏览，可让局域网与国内直连站点不走机场流量。游戏或会议若套餐含专线优化项，优先选用对应策略组，而不是在节点列表里反复盲点。

日常维护

订阅有更新时在客户端执行一次刷新即可。设备数量请控制在套餐限额内。流量将尽时先收紧分流规则，再考虑升级，避免把下载类任务放到代理通道。

常见问题

44F网络是什么？和 VPN、梯子有何关系？

44F网络以机场订阅方式提供网络加速能力。用户下载客户端并导入订阅后选择节点连接，使用方式接近常见的 VPN 梯子与加速器，区别在于配置中心是订阅链接而不是单一服务器地址。

第一次使用需要准备哪些东西？

需要一台可联网设备、所选套餐对应的订阅链接，以及本页客户端区域中的软件。按「选定套餐 → 取得订阅 → 下载客户端 → 导入 → 连接」的顺序操作即可，无需额外硬件。

导入订阅后看不到节点怎么办？

多数情况是链接复制不完整或尚未点击更新。请重新复制整段订阅地址，在客户端执行更新，并确认该客户端支持当前订阅格式。仍为空时，可更换本页列出的其他客户端再导入同一链接。

可以同时在多台设备上使用吗？

可以。同时在线台数以你购买的套餐说明为准，请在套餐区核对各版本限额。超出限额时，部分设备可能无法稳定在线，优先关掉闲置客户端再连接。

流量不够用时如何处理？

可等待当前周期重置，或改选更高流量版本。使用中建议用规则分流，让系统更新、大文件下载走直连，把机场流量留给需要加速的访问。

必须使用指定客户端吗？在哪里下载？

请以本页「客户端下载」区域列出的版本为准，这是 44F网络官方下载入口所对应的软件。不同系统选择对应安装包，安装后导入同一份机场订阅即可，不必为每台设备单独改配置。

已经连接，部分网站仍打不开？

先确认客户端处于已连接且代理模式有效，再尝试更换节点或调整规则。流媒体等站点的可用性与套餐解锁范围有关，请对照套餐说明，而不是反复重装软件。
